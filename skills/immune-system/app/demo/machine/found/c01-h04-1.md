## Bug
Pinned notes disappear when a notebook is renamed. This affects people using Lantern, a fictional shared notebook.

## Trigger
1. Open the isolated Lantern notebook fixture.
2. Exercise the **rename** case in notebooks.
3. Read the resulting page and saved notebook.

## Evidence
> The visible result and the saved notebook disagree.

The fixture records the before and after values, not just the exit code.

## Reproduction
```sh
lantern check notebooks --case rename --isolated
# exit 1: expected invariant did not hold
```

## Guard idea
Check the rename boundary before accepting the change.
