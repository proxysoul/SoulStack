# Feedback rounds

The first edit made this way went through seven rounds. Each line is what the owner said and what fixed it. Start where the last round ended.

1. **"Underwhelming. Very stable and slow. It's supposed to be a meme, not an edit."** The first cut was a tasteful promo: slow pans, cards fading in. Fix: flashes, invert frames and glitch on every drop, features thrown around on every bass hit, theme colour strobing on the beat.
2. **"Still static. It should have screen changes and actual pictures."** Fix: real product screenshots in every shot, a cut on every downbeat, the background a moving duotone of the current shot.
3. **"The text is lagging behind the lyrics, and when the beat drops a picture just stays there."** The captions used Whisper times. Fix: stems, forced alignment, captions 30 to 60 ms ahead; the shot after the drop changes on the next downbeat instead of holding.
4. **"You're duplicating things, I don't see me behind the computer smirking, go faster from v1 to v2 to v3; v3 is the main focus; put something in the background."** Fix: one feature per slot with no repeats on screen, the maker silhouette at the laptop with a smirk, the origin compressed into the build-up, the drops given to the current version, dimmed product imagery behind everything.
5. **"Show how much I spent and how much I saved, be smart about it."** Fix: a printed receipt with real numbers: usage value, what was paid, cache savings, and the cost of the same work on the alternatives from a measured benchmark ratio, ending in a stamped total.
6. **"Make it wild: crazy motion, text that looks written on. Same for the money, animate the numbers and the type."** Fix: `write_on`, `typewriter`, `scramble`, `slam` with ghosts, `explode`, numbers counting up and bouncing, the receipt printing line by line.
7. **Delivery.** Both formats, opened in QuickTime without playing, AirDropped to the owner's phone.
